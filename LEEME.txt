MONACO 98.7 FM — PAQUETE NETLIFY

1) Subí el contenido de esta carpeta (no la carpeta comprimida dentro de otra carpeta) a un repositorio GitHub y conectalo con Netlify, o arrastrá el ZIP a Netlify Drop.
2) Para guardar noticias/programación de forma permanente, vinculá el sitio a un repositorio Git y habilitá Netlify Functions. La aplicación usa Netlify Blobs; el paquete incluye package.json para instalar @netlify/blobs.
3) En Netlify > Site configuration > Environment variables agregá:
   MONACO_ADMIN_PASSWORD = monaco2026
   (Podés cambiarla por otra clave más segura. Si no la configurás, el código usa monaco2026 como clave inicial.)
4) Después de agregar variables, hacé un nuevo deploy.
5) El acceso al administrador está oculto en la esquina inferior derecha: hacé clic en esa esquina.
6) Las noticias y la programación se guardan en Netlify Blobs; no se guardan en una carpeta /uploads del sitio estático. Las imágenes se guardan como datos en Blobs.
7) Reemplazá assets/monaco.png y assets/portada.png por tus archivos PNG reales, conservando exactamente esos nombres. El PNG del logo se usa también como icono de pestaña y de instalación.
8) La instalación PWA aparece desde el navegador cuando se cumplen los requisitos del navegador. En iPhone/iPad se instala desde Compartir > Añadir a pantalla de inicio.
9) La radio se reproduce por /.netlify/functions/proxy, que intenta conectarse al servidor indicado. Un proxy no puede garantizar disponibilidad si el servidor de origen bloquea conexiones, exige cabeceras especiales o está fuera de servicio.
